# Portfolio

Victor Kimani’s personal site: who I am, where I’ve worked, what I’ve built, and articles about decisions in the AI systems I run, with the numbers and the code behind them.

## Repository structure

| Folder | Contents |
| --- | --- |
| [`portfolio/`](portfolio/) | The Next.js site. See its [README](portfolio/README.md) for local development and how to add an article. |
| [`experiments/`](experiments/) | Code and raw results that the articles link to. |

## Built with

- Next.js 16 and React 19, with TypeScript
- MDX articles compiled at build time, with Shiki for code
- CSS modules and design tokens, with light and dark themes
- Charts drawn as React components, and diagrams as theme-aware SVG
