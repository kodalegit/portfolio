# Portfolio

Victor Kimani’s personal portfolio, showcasing work in AI engineering, machine
learning, and full-stack software development.

The site includes an introduction, background and experience, selected projects
with screenshots and demos, and links to a résumé and contact profiles.

## Built with

- Next.js and TypeScript
- Tailwind CSS
- Framer Motion
- Radix UI and Lucide icons

## Repository structure

The Next.js application lives in [`portfolio/`](portfolio/). Its components cover
the introduction, about, projects, experience, and contact sections.

See the [application README](portfolio/README.md) for local development commands.
