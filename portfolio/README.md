# Portfolio app

A responsive portfolio built with Next.js, TypeScript, and Tailwind CSS.
It presents Victor Kimani’s background, AI and software engineering projects,
professional experience, and contact links. Project cards include screenshots,
technology stacks, and links to demos, live sites, and source code where available.

## Local development

Use Node.js 20 or later and pnpm. From this directory, run:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Open [localhost:3000](http://localhost:3000) to view the site.

## Commands

- `pnpm dev` — start the development server.
- `pnpm lint` — run ESLint.
- `pnpm build` — create a production build.
- `pnpm start` — serve the production build.
